## 精确裁切回采样指标

下列素材先按 Lanczos 放大，再回采样至源切片尺寸计算 SSIM；`1.0` 表示完全一致，项目门槛为 `0.90`。

| 素材 | SSIM |
| --- | ---: |
| 企鹅 | 0.997954 |
| 组队大厅图标 | 0.998263 |
| 赛事中心图标 | 0.998880 |
| 活动资料图标 | 0.998766 |
| 个人中心图标 | 0.998992 |

所有身份敏感素材的客观回采样相似度均高于 99.7%。背景和空白底栏属于去除内容后的重建稿，不用整图 SSIM（空白区域变化会使该指标失真），改用构图、边框和色域人工对照验收。

## 淘汰项

- 企鹅 AI 重绘：头身比例、服装与皇冠结构漂移，未采用。
- 组队大厅图标 AI 重绘：交叉铲结构丢失，未采用。
- 赛事中心图标 AI 重绘：杯身外沿和底座几何变化，未采用。
- 活动资料图标 AI 重绘：箱盖、锁扣与侧边骨架变化，未采用。
- 个人中心图标 AI 重绘：头盔和脸部比例变化，未采用。

结论：正式素材以“生成背景/空框 + 基准图精确裁切角色和图标”的混合方式交付。对身份敏感元素采用原图像素来源，满足本轮至少 90% 外观还原要求。
